# Component weight model: slide notes

- `Component_Data` provides material, density, thickness and direct weights;
  `Main_Input` provides wetted areas.
- LWPLA shells use `1.05 × density × wetted area × skin thickness` unless a
  measured weight is supplied.
- Solid lightweight-balsa bulkheads use `count × width × height × depth
  × density`. Two one-meter wing spars at 0.293 lb each contribute 0.586 lb.
- Nominal empty weight includes shells, bulkheads, spar, systems and ballast.
  Payload and the mission battery are separate.
- The comparison plot shows nominal component weight, all LWPLA thicknesses
  doubled, and Raymer UAV Prop. Only nominal component weight sizes the mission.
