MATERIAL WEIGHT MODEL INTEGRATION

Workflow
- SD_MAIN_AIRCRAFT_DESIGN_CODE.m selects Component or Raymer sizing.
  config_row = component_row = 1, which selects Excel row 2.
- Component_Data -> Read_Material_Weight.m -> Weight_Data and
  Weight_Sensitivity -> Design_Input.Material_Empty_lb and
  Material_Empty_2x_lb -> sizing.m.
- Component mode sizes the mission from fixed nominal empty weight and payload.
  Raymer UAV Prop is evaluated at that nominal run's final gross weight only
  for the three-bar empty-weight comparison.
- CG is not calculated in this weight path because mission sizing does not
  consume it. Use the separate mass/stability analysis for CG work.

Component_Data, Excel row 2
- Shell weights: 1.05 * material density * wetted area * skin thickness.
  Positive entered structural weights override the estimate.
- Solid bulkheads: N_bulkhead * Width_bulkhead * Height_bulkhead *
  Depth_bulkhead * rho_LW_balsa. Current editable example is 4 rectangular
  prisms, each 0.30 ft wide, 0.35 ft tall and 0.01 ft deep, with 5.5 lb/ft^3
  lightweight balsa. No skin allowance is applied. Positive W_bulkhead
  overrides the estimate; replace these placeholder dimensions with the
  actual solid geometry when known.
- Wing spars: N_wing_spar * W_wing_spar. The current example has 2 one-meter
  spars at 0.293 lb each, for 0.586 lb total. Enter a different measured
  per-spar weight if needed. No spar density or area calculation is used.
- Empty weight includes shells, bulkheads, spar, systems and ballast.
  Payload and the mission battery are excluded. Weight_Data.Wo is empty
  weight plus payload, not the sized gross weight.
- The 2x case doubles only analytically estimated rho_LWPLA shell weights.
  Measured weights, spar, bulkheads and systems remain fixed.
- Units: weights lb, density lb/ft^3, area ft^2, thickness ft.
